# Controller Binds

Minecraft 1.21.11 (Fabric) 向けのコントローラー入力mod。

コントローラーの入力を「キー」ではなく「キーコンフィグの項目（操作）」に直接割り当てます。
キーボードの割り当てとは独立しているため、キーボードでは同じキーを使っている操作をコントローラーでは別々の入力にしたり、その逆を行ったりできます。

## 特徴

- キーコンフィグの全項目（バニラ・Mod 共通）に割り当て可能。1つの入力を複数の操作に割り当てることもできます（重複可）
- キーコンフィグにないマウス操作の代替（マウス移動・左/中/右クリック・ホイール）と Esc を用意
  - マウス移動はゲーム中は視点操作、画面表示中はカーソル操作になります（感度・反転は本体のマウス設定に従います）
- 初期状態ではすべて未割り当て。ゲームパッド以外（フライトスティック・ハンドル等）も想定し、GLFW の生のボタン番号・軸番号で扱います
- 割り当てはコントローラー機器ごとに保存（`config/controllerbinds.json`）

## 使い方

1. コントローラーを接続してゲームを起動する
2. F6（キーコンフィグの「コントローラー割り当てメニューを開く」で変更可）で割り当てメニューを開く
3. 項目のボタンを押してから、割り当てたいコントローラーの入力を押す（Esc: 取消 / Delete: 解除）

スティックやトリガーが触れていないのに「入力中」に表示される場合は、手を離した状態で「中立位置を記録」を押してください。

## 動作の詳細

- ゲーム中: 割り当てた項目の押下状態とクリックを直接操作します。キーボード側の状態とは OR で合成されます
- 画面（インベントリ等）表示中: 画面はキー入力しか受け付けないため、その項目に現在割り当てられているキーボードのキーとして画面に通知します
- フルスクリーン切り替え・スクリーンショット・HUD 非表示・デバッグ画面などキーイベントで直接処理される項目は、対応する処理を直接呼び出します
